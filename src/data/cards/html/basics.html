HTML Basics

What is Html?
HTML stands for Hypertext markup language.
It is standard language to create web pages.
HTML is not a programming language.
It is a markup language, meaning it describes the structure of a webpage.

HTML Document Structure

<!DOCTYPE html>
Tells the browser that this document is HTML5.

<html>
Root element of the webpage.
Everything should be inside it.

<head>
Contains information about the webpage.
Examples:
title
CSS
JavaScript
meta tags
Nothing inside <head> is directly visible.

<title>
Shown on the browser tab.

<body>
Everything visible to users goes inside the body.

Elements and Tags

A tag looks like this: <p> 
A closing tag is : </p>
Together they form an element
Example: <p>This is nagendra </p>
Some tags do not need closing Tags.
    <br>, <hr>, <img>

Headings

    HTML provides six heading levels.
    h1 to h6.

Paragraphs

    Paragraphs are written using <p>

Comments

    Comments are ignored by browsers.

Important tags:
    Line Break(<b>)
    Horizontal line (<h>)
