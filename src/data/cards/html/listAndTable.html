List And Table Tags

List Tags

| Tag  | Description                                      | Example                                          |
| ---- | ------------------------------------------------ | ------------------------------------------------ |
| <ol> | Creates an ordered list (numbered list)          | `<ol>`                                     |
| <ul> | Creates an unordered list (bullet list)          | `<ul>`                                     |
| <li> | Defines an item inside ordered or unordered list | `<li>Java</li>`                      |
| <dl> | Creates a description list                       | `<dl>`                                     |
| <dt> | Defines the term/name in a description list      | `<dt>HTML</dt>`                      |
| <dd> | Defines the description of a term                | `<dd>HyperText Markup Language</dd>` |

Ordered List Tag

| Tag / Attribute | Description                            | Example                |
| --------------- | -------------------------------------- | ---------------------- |
| <ol>            | Creates numbered list                  | `<ol>`           |
| `type`          | Changes numbering style                | `<ol type="A">`  |
| `start`         | Starts numbering from a specific value | `<ol start="5">` |
| `reversed`      | Displays list in reverse order         | `<ol reversed>`  |

Unordered List Tag

| Tag / Attribute | Description          | Example                    |
| --------------- | -------------------- | -------------------------- |
| <ul>            | Creates bullet list  | `<ul>`               |
| `type`          | Changes bullet style | `<ul type="square">` |

Description List Tags

| Tag  | Description                    | Example                                     |
| ---- | ------------------------------ | ------------------------------------------- |
| <dl> | Container for description list | `<dl>`                                |
| <dt> | Description term/title         | `<dt>Java</dt>`                 |
| <dd> | Description details            | `<dd>Programming Language</dd>` |

Table Tags

| Tag        | Description                 | Example                                           |
| ---------- | --------------------------- | ------------------------------------------------- |
| <table> | Creates an HTML table       | `<table>`                                   |
| <caption> | Adds table title/caption    | `<caption>Employee Details</caption>` |
| <tr> | Creates a table row         | `<tr>`                                      |
| <th> | Creates table header cell   | `<th>Name</th>`                       |
| <td> | Creates table data cell     | `<td>Nagendra</td>`                   |
| <thead> | Groups table header section | `<thead>`                                   |
| <tbody> | Groups table body section   | `<tbody>`                                   |
| <tfoot> | Groups table footer section | `<tfoot>`                                   |
| <colgroup> | Groups columns for styling  | `<colgroup>`                                |
| <col> | Defines column properties   | `<col span="2">`                            |

Table Attributes

| Attribute | Used With  | Description              | Example                    |
| --------- | ---------- | ------------------------ | -------------------------- |
| `border`  | <table>    | Adds border around table | `<table border="1">` |
| `colspan` | <td>, <th> | Merges multiple columns  | `<td colspan="3">`   |
| `rowspan` | <td>, <th> | Merges multiple rows     | `<td rowspan="2">`   |

colspan & rowspan Tags

| Attribute | Description                               | Example                  |
| --------- | ----------------------------------------- | ------------------------ |
| `colspan` | Combines two or more columns horizontally | `<td colspan="2">` |
| `rowspan` | Combines two or more rows vertically      | `<td rowspan="2">` |
