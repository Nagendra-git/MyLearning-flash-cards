Anchor Tag

Which protocols are commonly used with the href attribute?
✅ Answer:
https:// → Websites
mailto: → Email
tel: → Phone
# → Same-page navigation

| Question                            | Answer                                                |
| ----------------------------------- | ----------------------------------------------------- |
| Purpose of ``                       | Creates hyperlinks                                    |
| Mandatory attribute                 | `href`                                                |
| Open new tab                        | `target="_blank"`                                     |
| Email link                          | `mailto:`                                             |
| Phone link                          | `tel:`                                                |
| Download file                       | `download`                                            |
| Website link                        | `https://...`                                         |
| Same-page link                      | `#sectionId`                                          |
| Another HTML page                   | `about.html`                                          |
| Difference between `href` and `src` | `href` references a resource; `src` embeds a resource |

Image Tag

The <img> tag is used to display an image on a webpage.
It is a void element.
src specifies the location (path or URL) of the image.
alt provides alternative text if the image cannot be displayed.
What do width and height do?
✅ Answer
They define the image dimensions.
What is the purpose of <figure>?
    It is a groups media like images, diagrams, or code snippets with an optional caption.
What is <figcaption> used for?
✅ Answer
<figcaption> adds a caption to a <figure>.

| Topic            | Remember                            |
| ---------------- | ----------------------------------- |
| Display image    | <img src="image.jpg" alt="Image"> |
| Image source     | `src`                               |
| Alternative text | `alt`                               |
| Relative path    | `images/photo.jpg`                  |
| Parent folder    | `../images/photo.jpg`               |
| Caption          | <figcaption>                      |
| Audio            | <audio controls>                  |
| Video            | <video controls>                  |
| Embed YouTube    | <iframe>                          |
| Browser icon     | Favicon (<link rel="icon">)       |
