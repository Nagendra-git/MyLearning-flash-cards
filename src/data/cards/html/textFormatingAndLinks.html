Text Formatting & Links

Text Formatting Tags

| Tag        | Purpose         | Example Output |
| ---------- | --------------- | -------------- |
| `<b>`      | Bold            | Bold           |
| `<strong>` | Important text  | Important      |
| `<i>`      | Italic          | Italic         |
| `<em>`     | Emphasized text | Emphasized     |
| `<u>`      | Underline       | Underlined     |
| `<mark>`   | Highlight       | Highlighted    |
| `<small>`  | Smaller text    | Small          |
| `<del>`    | Deleted text    | ~~Deleted~~    |
| `<ins>`    | Inserted text   | Underlined     |
| `<sub>`    | Subscript       | H₂O            |
| `<sup>`    | Superscript     | x²             |

Hyper Links

The anchor tag creates hyperlinks.

syntax:
<a href=URL>Link Text<a>

Open new tab :
use target="_blank"

Local Links:- Navigation between pages.
<a href="about.html">About</a>
<br>
<a href="contact.html">Contact</a>

Email Links:-When clicked, it opens the default email application.
<a href="mailto:abc@gmail.com">
Send Email</a>

Phone Links: Useful for mobile devices.
<a href="tel:+919876543210">
Call Me
</a>

Download Links: If a file exists in your project.
<a href="resume.pdf" download>
Download Resume
</a>

Absolute vs Relative URLs:-
Absolute URL :Points to another website.
<a href="https://www.youtube.com">
YouTube</a>
Relative URL :Points to a file in your project.
<a href="about.html">
About</a>

Combining Formatting with Links:
<a href="https://www.linkedin.com">
<b>Visit My LinkedIn</b>
</a>

| Question             | Answer                                                                 |
| -------------------- | ---------------------------------------------------------------------- |
| <b> vs <strong>  | <b> is for visual bold styling; <strong> adds semantic importance. |
| <i> vs <em>      | <i> is for italic styling; <em> adds semantic emphasis.            |
| Email link           | <a href="mailto:user@example.com">Email</a>                          |
| Phone link           | <a href="tel:+919876543210">Call</a>                                |
| download attribute | Downloads the linked file instead of opening it.                       |
