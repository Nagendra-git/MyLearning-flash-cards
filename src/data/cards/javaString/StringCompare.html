== vs equals()

== -> Checks Reference

Pseudo Code
String s1 = "java";
String s2 = "java";
sysout(s1==s2); //true

equals() -> Checks Content.

Pseudo Code
String s1 = new String("java");
String s2 = new String("java");
sysout(s1.equals(s2));//true (content is same)
sysout(s1 == s2 ); //false (Diffrent objects)

equalsIgnoreCase() :- Ignores uppercase/lowercase differences.

Pseudo Code
String s1 = "JAVA";
String s2 = "java";
System.out.println(s1.equals(s2)); //false
System.out.println(s1.equalsIgnoreCase(s2)); // true

compareTo() :- Compares strings lexicographically (dictionary order)

Returns:
0 → Strings are equal
Positive number → First string is greater
Negative number → First string is smaller
Pseudo Code
System.out.println("Apple".compareTo("Apple"));//0
        System.out.println("Banana".compareTo("Apple"));//(B)66 - (A)65 = 1
        System.out.println("Apple".compareTo("Banana"));//(A)65 - (B)66 = -1

compareToIgnoreCase():- Works exactly like compareTo(), but ignores case.

Pseudo Code
String s1 = "JAVA";
String s2 = "java";
System.out.println(s1.compareTo(s2)); //J(74) - j(106) = -32
System.out.println(s1.compareToIgnoreCase(s2));//0

🎯 Interview Takeaway: When to use each
    ==:Use only when you intentionally want to know whether two references point to the same object.
    equals():Use to compare the actual text of strings. This is the most common choice in application code.
    equalsIgnoreCase(): Use for case-insensitive equality checks, such as comparing usernames or commands.
    compareTo(): Use for sorting or determining alphabetical order.
    compareToIgnoreCase(): Use for case-insensitive sorting or ordering.
