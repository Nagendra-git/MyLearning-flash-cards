Java Script

JavaScript is a programming language used to add logic and behavior to applications.

JavaScript needs an environment that can execute it.
The two environments you should understand first are:
Browser
   ↓
JavaScript runs inside the browser

Node.js
   ↓
JavaScript runs outside the browser

JavaScript Engine

A JavaScript engine is the component that executes JavaScript code.
For example:   
JavaScript Code
       ↓
JavaScript Engine
       ↓
Machine Instructions
       ↓
      CPU

Popular engines:
Chrome       → V8(V8 is Google's JavaScript engine.)
Firefox      → SpiderMonkey
Safari       → JavaScriptCore
Node.js      → V8
The important one for us initially is V8.

JavaScript Runtime

A runtime environment provides everything needed to execute JavaScript in a particular environment.
JavaScript Runtime
│
├── JavaScript Engine
├── APIs
├── Event Loop
├── Queues
└── Other environment features

Browser Runtime

When JavaScript runs inside Chrome, the environment looks roughly like:
Chrome
│
├── V8
│
├── DOM APIs
├── Web APIs
├── Storage APIs
├── Fetch APIs
└── Event System

Browser vs Node.js

document.querySelector("h1");
Browser: Works because the browser provides document.
Node.js: ormally doesn't work because Node.js doesn't provide the browser DOM.

const fs = require("fs");
Node.js provides the filesystem API.
The browser doesn't give normal webpage JavaScript unrestricted filesystem access.

ECMAScript

You will see the term ECMAScript frequently.
ECMAScript is the standard/specification for the JavaScript language.
ECMAScript
     ↓
Language specification
     ↓
JavaScript implementations
