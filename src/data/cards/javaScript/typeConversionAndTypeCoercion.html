Type Conversion & Type Coercion

Type Conversion

Type conversion means you explicitly convert a value from one type to another.
Common conversion functions:
Number()
String()
Boolean()

1.String → Number:
let value = "100";
let result = Number(value);
console.log(result);//100
Number("hello")// NAN

2.Number → String:
let age = 25;
let value = String(age);
console.log(typeof value);//string

3.Boolean Conversion:
Boolean(1);        // true
Boolean(0);        // false
Boolean("hello");  // true
Boolean("");       // false

Type Coercion

Type coercion happens when JavaScript automatically converts a value from one type to another.
You didn't explicitly request the conversion.
+ -> concatination ("10"+5) => 105//string
- -> ("10"-5) => 5
* -> ("10" * 5) => 50
/ -> ("10"/5) =>2

== vs ===

== : Loose Equality
JavaScript can perform type coercion.
5 == "5"
Result:true

===:Strict Equality
No type coercion.
5 === "5"
Result:false
Because:
5       → number
"5"     → string
Different types :false
