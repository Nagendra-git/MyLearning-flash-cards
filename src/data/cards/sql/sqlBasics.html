SQL Basics

Data:- Data is a raw-fact which describes the attributes of an entity.
Database:- Database is a place or medium in which we store the data in a systematic and organized manner.
DBMS :- It is a software which is used to maintain and manage the database.

  1. Security and autherization are the two important features that DBMS provids.
  2. We use query language to communicate or interact with DBMS.
  3. DBMS stores the data in the form of files.

RDBMS(RELATIONAL DATABASE MANAGEMENT SYSTEM)

It is a type of DBMS software in which we store the data in the form of tables(rows & columns).
we use SQL to comunicate or interact with RDBMS.
