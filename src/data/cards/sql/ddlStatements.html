DDL Statements

DDL is used to construct an object in the database and deals with the structure of the object.

It has five Statements:
1.CREATE
2.RENAME
3.ALTER
4.TRUNCATE
5.DROP

CREATE Statement

SQL code
CREATE TABLE Table_Name
(
    comumn_name1 datatype constraint_type,
    comumn_name2 datatype constraint_type,
    ..
    comumn_namen datatype constraint_type,
);

RENAME Statement

SQL code
RENAME Table_Name TO New_Table_name;

ALTER Statement

SQL code
ALTER TABLE Table_Name ADD COLUMN column_name;
ALTER TABLE Table_Name DROP COLUMN column_name;
ALTER TEABLE Table_Name RENAME COLUMN column_name To new_column_name;
ALTER TEABLE Table_Name MODIFY column_name new_data_type;
ALTER TABLE Table_Name MODIFY column_name Existing_datatype [NULL]/NOT NULL;

TRUNCATE Statement

SQL code
TRUNCATE TABLE Table_Name;

DROP Statement

SQL code
DROP TABLE Table_Name;
        
To Recover the table(oracle)
SQL code
FLASHBACK TABLE Table_Name TO BEFORE DROP;

To DELETE the table form BIN Folder

SQL code
PURGE TABLE Table_Name;
        
Note: ALL DDL Statements are auto commit Statements
